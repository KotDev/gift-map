# Карта подарков

Маленькое PWA-приложение-сюрприз: карта из пяти остановок, пять круток,
подарки открываются по датам. Это чистая статика — HTML, CSS и JS без сборки,
зависимостей и сервера. Всё приложение живёт в одном `index.html`;
`manifest.webmanifest` и `sw.js` делают его устанавливаемым на телефон
и работающим офлайн.

## Состав

| Файл | Зачем |
|---|---|
| `index.html` | само приложение: разметка, стили и логика в одном файле |
| `manifest.webmanifest` | манифест PWA: имя, иконки, полноэкранный режим |
| `sw.js` | service worker: кэш и офлайн-режим (навигация — network-first) |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | иконки приложения (непрозрачные PNG) |
| `VID_*`, `video*.mp4` | видео-мемы под подарками и фоновый ролик |
| `serve.sh` | локальный сервер для проверки на телефоне по Wi-Fi |
| `tools/make_icons.py` | генератор иконок на чистом Python 3 |

## Посмотреть на Mac

Из папки проекта:

```bash
cd /Users/dakotovev/gift-app
./serve.sh
```

Скрипт напечатает адреса и запустит сервер на порту 8000. Открой
<http://localhost:8000>. Остановить — `Ctrl+C`.

Если `./serve.sh` не запускается, выдай ему право на исполнение:

```bash
chmod +x serve.sh
```

Можно и без скрипта:

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

## Открыть на iPhone (та же Wi-Fi)

1. Mac и iPhone должны быть в одной сети Wi-Fi.
2. Запусти `./serve.sh` — он покажет адрес вида `http://192.168.1.5:8000`.
3. На iPhone открой Safari и введи этот адрес.

Если страница не открывается: проверь, что Wi-Fi не «гостевой» (в гостевых
сетях устройства часто изолированы друг от друга), разреши Python входящие
соединения в системном firewall macOS и убедись, что IP определился
(`ipconfig getifaddr en0`).

## Установить на экран «Домой»

В Safari: кнопка «Поделиться» (квадрат со стрелкой) → **«На экран „Домой“»**
→ «Добавить». Приложение появится иконкой и будет открываться на весь экран,
без адресной строки.

> **Важно про локальный HTTP.** По адресу вида `http://192.168.x.x:8000`
> service worker не работает: iOS включает его только для HTTPS (исключение —
> `localhost`, но с телефона это не он). Поэтому при локальной проверке
> офлайн-режим не включится, а после выхода из Wi-Fi приложение не откроется.
> Полноценный офлайн появляется только после публикации по HTTPS — например,
> на GitHub Pages.

## Опубликовать на GitHub Pages

1. Создай репозиторий на GitHub. Для бесплатного Pages проще **Public**.
2. Залей содержимое этой папки в **корень** репозитория (важно, чтобы
   `index.html` лежал в корне, а не во вложенной папке). Через терминал:

   ```bash
   cd /Users/dakotovev/gift-app
   git init
   git add .
   git commit -m "Подарки: PWA"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

   Можно и через веб-интерфейс: «Add file → Upload files» и перетащить файлы.
   Папку `tools/` заливать не обязательно — она нужна только для генерации
   иконок.
3. В репозитории: **Settings → Pages → Build and deployment**.
   Source — **Deploy from a branch**, Branch — **`main`**, папка — **`/ (root)`**,
   затем **Save**.
4. Через минуту-две GitHub покажет ссылку вида
   `https://<user>.github.io/<repo>/`. Открой её в Safari на iPhone.
5. Установи на «Домой» тем же способом: «Поделиться» → «На экран „Домой“».

После первого открытия по HTTPS service worker скачает и закэширует
приложение, и дальше оно будет работать офлайн — в том числе без Wi-Fi.

**Обновления.** Когда меняешь файлы, поднимай версию кэша в `sw.js`
(`const CACHE = 'gift-v12'` → `'gift-v13'`) и заливай изменения. После
этого открой приложение один-два раза с интернетом — новая версия
подтянется в фоне.

**Публичный репозиторий.** На бесплатном GitHub Pages репозиторий должен
быть **Public**, а значит, исходники (в том числе `notifyUrl`) видны всем.
Для секретного топика ntfy это нормально, если он длинный и случайный.

## Как менять даты

В начале `<script>` в `index.html` есть блок `CONFIG`. У каждого подарка
есть поле `date` в формате `YYYY-MM-DD` — дата, с которой подарок
открывается. Схематично:

```js
const CONFIG = {
  gifts: [
    { date: '2026-12-01', /* ... */ },
    { date: '2026-12-02', /* ... */ }
  ]
};
```

Меняй только строки дат; остальные поля не трогай. Точный набор полей
смотри в самом файле — структура может немного отличаться от схемы выше.

## Как добавить скриншоты подарков

У подарка в `CONFIG` есть поле `art`. В него кладётся картинка в виде
base64 data-URI:

```js
art: 'data:image/png;base64,iVBORw0KGgoAAAANSUhEUg...'
```

Получить такую строку из файла на macOS:

```bash
base64 -i podarok.png | pbcopy
```

и вставить содержимое буфера в кавычки после `base64,`. Бери картинки
небольшими (примерно 300–600 px по ширине, PNG/JPEG/WebP): каждая сотня
килобайт превращается в ~130 КБ текста внутри `index.html`, а файл должен
оставаться лёгким. Если `art` пустой или его нет, приложение покажет
заглушку — картинки можно добавить позже.

## Как добавить видео-мем под подарком

У каждого подарка в `CONFIG` есть два необязательных поля:

```js
meme: 'video.mp4',      // видео, GIF или картинка
memeAlt: 'Линзы'        // подпись для доступности
```

Если `meme` нет или он пустой — блок с мемом просто не выводится.

Сейчас подключены пять роликов (порядок намеренно вразнобой):

| Подарок | Файл |
|---|---|
| Цветы и вкусняшки | `video%2520(1).mp4` (в `CONFIG` путь закодирован как `video%252520(1).mp4`) |
| Линзы | `VID_20261120_193334_372.mp4` |
| Тонометр | `VID_20261120_193256_222.mp4.mov` |
| Анализы | `video.mp4` |
| Сумка | `VID_20261120_193201_077.mp4.mov` |

Видео проигрывается по кругу (`loop playsinline`) и сразу пытается включить
звук. Если браузер блокирует звук без жеста, ролик стартует без звука и
показывает красную кнопку **ЗВУК** — по нажатию звук включается. На iOS
звук разблокируется первым тапом по странице. Поддерживаются `.mp4`,
`.webm`, `.mov`, а также `.gif` и обычные картинки. Файл можно держать
в корне проекта или переложить в папку и поменять путь в `meme`.

Большие ролики не добавляй в `PRECACHE` в `sw.js`: service worker закэширует
их после первого просмотра. При замене файла подними версию кэша
(`gift-v8` → `gift-v9`). Если видео не загрузилось, блок тихо скрывается.

## Интро при запуске

При каждом открытии приложения поверх экрана идёт короткая неоновая заставка
в духе трейлера: сначала пачкой вспыхивают все пять иконок подарков, затем
появляется большой подарок с миганием неоновой вывески, а под ним выезжает
«Привет любимка» (белое + красное). Через ~5.6 секунды или по тапу/Enter/
Escape она уходит. Разметка — блок `.intro` в начале `<body>`, тайминги —
в `startIntro()`, закрытие — `dismissIntro()`.

## Анимация крутки

После нажатия «Крутить» на сцене работает та же логика, что в интро:
пять иконок подарков гаснут одна за другой, затем в центре появляется
иконка выпавшего подарка, снизу выезжает коробка, иконка падает в неё —
и раскрывается карточка с видео (со звуком), названием подарка и кнопкой
«Забрать». Тайминги — в `startSpin()` (`prepareSpinSequence` + четыре
`setTimeout`), разметка — `.spin-stage` внутри `.wish-block`.

## Уведомление «она открыла подарок»

В `CONFIG` есть `notifyUrl`. Пустая строка — уведомления выключены.
Самый простой вариант без своего сервера — [ntfy](https://ntfy.sh):

1. Придумай длинный секретный топик, например
   `alina-gifts-7f3k9x2m`.
2. Поставь приложение **ntfy** на iPhone (App Store) или открой
   `https://ntfy.sh/<топик>` в браузере.
3. Подпишись на этот топик.
4. В `CONFIG` впиши:
   ```js
   notifyUrl: 'https://ntfy.sh/alina-gifts-7f3k9x2m',
   ```
5. Задеплой. При каждом новом открытом подарке придёт пуш вида:
   «Алина открыла подарок 2/5 — Линзы. Открыто: 2 из 5.»

Уведомление отправляется один раз на подарок и только при новой крутке,
не при перечитывании. `notifyUrl` — обычный вебхук: подойдёт и свой
Cloudflare Worker, и Formspree, и что угодно, что принимает `POST`.

> **Приватность.** Сайт статический, поэтому URL вебхука виден в исходниках.
> Если репозиторий публичный, топик сможет увидеть любой. Делай его длинным
> и случайным; для полной приватности нужен приватный репозиторий (Pages для
> приватных — на платном тарифе) либо свой прокси, который прячет токен.

## Иконки подарков

В карточке каждого подарка есть анимированная SVG-иконка в фонк-стиле
(красный неон + кислотный акцент): цветок, линза, тонометр, пробирка, сумка.
Отдельных файлов нет — иконки рисует функция `giftIcon()` в `index.html`,
анимация сделана SMIL внутри SVG. Кэш поднимать не нужно: всё внутри
`index.html`.

## Фоновое видео

Фон — отдельный ролик, который крутится без звука за интерфейсом. Путь
задаётся в `CONFIG`:

```js
bgVideo: 'video%252520(1).mp4'
```

Положи новый файл в корень проекта и поменяй строку. Если имя содержит
пробелы или `%`, закодируй его для URL: `video (1).mp4` → `video%20(1).mp4`,
а `video%2520(1).mp4` → `video%252520(1).mp4`. Чтобы фон не крутился,
поставь `bgVideo: ''`.

## Как тестировать

Приложение работает в прод-режиме: подарок открывается только в свою дату
(в 00:00 по местному времени) и позже, раньше — никогда. Дев-режима больше
нет. Чтобы посмотреть будущий подарок локально, временно поменяй дату в
`CONFIG.gifts[].date` на сегодня, проверь и верни обратно.

```bash
./serve.sh
# открыть http://localhost:8000
```

Если после правок видишь старую версию — обнови страницу с очисткой кэша
или подними версию `CACHE` в `sw.js`.

## Пересобрать иконки

Иконки уже сгенерированы, но если понадобится изменить рисунок или размеры:

```bash
python3 tools/make_icons.py          # 180, 192, 512
python3 tools/make_icons.py 96 1024  # свои размеры
```

Скрипт использует только стандартную библиотеку Python 3 (без PIL) и кладёт
файлы `icon-<размер>.png` в корень проекта.
